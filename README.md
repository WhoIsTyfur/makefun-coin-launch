# makefun-coin-launch

Entry for the make.fun bounty [Race to launch a real coin on Solana](https://make.fun/bounty/makefun-coin-launch-01).

The agent creates a coin on pump.fun from its own wallet, with the make.fun ghost from the press kit
as its logo and the description `made for make.fun $1000 bounty`. `metadata.json` in this repo is
the coin's token metadata; its `image` is the press kit's file itself, https://make.fun/press/mark-1024.png.
